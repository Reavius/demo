# «Мечты» — пример сайта заведения

Онлайн-пример сайта всего заведения «Мечты» (кафе, клуб, мансарда, VIP): афиша, бронь стола, залы, банкеты, меню кухни
и карта бара, акции, новости, фотоотчёты, подарочные сертификаты, подписка, отзывы, вакансии, контакты — и админка для
управляющего (`admin.html`).

**Это пример для показа.** Даты, цены, вместимость, адрес и телефон — для примера. Заявки и правки в админке
сохраняются **только в браузере того, кто открыл**: у каждого свои, кнопка «Сбросить пример» в админке — к началу.
В рабочей версии заявки общие и сразу приходят администратору.

## Как открыть по ссылке

**GitHub Pages** (один раз): в этом репозитории **Settings → Pages → Build and deployment → Source: Deploy from a branch →
Branch: `main`, папка `/ (root)` → Save**. Через 1–2 минуты сверху появится ссылка — `https://reavius.github.io/demo/`.
Дальше каждое изменение в `main` выкладывается само.

Или **Netlify**: Add new site → Import an existing project → GitHub → `Reavius/demo` → Deploy (сборка не нужна,
папка — корень). Сайт тоже будет обновляться сам.

Админка: та же ссылка + `admin.html`.

## Откуда файлы

Сайт собирается из папки `venue/` репозитория барного гида (`Reavius/mechty-test`) — там же версия с сервером
(общие заявки, пароль админки, фото в файлах) и описание в README («Сайт заведения (пример)»). Обновить этот репозиторий:

```
node venue/build-static.mjs ../demo
```

(из папки барного гида; `.git`, этот README и `CNAME` не трогаются). Карта бара — снимок барного гида на момент сборки.
Поисковикам сайт закрыт (`noindex`).
